Formboard XR

FAU – Lehrstuhl FAPS | 10/2026 | Entwickler (Wiss. Hilfskraft)

KBL-Daten in VR: Montagetrainer für Kabelbäume, live im Browser

DatenKI / SimulationWebXRMeta Quest 3KBLThree.jsPython
Im Browser ausprobieren ↗Demo-Videos ↗Code auf GitHub ↗

Was?

  • Kabelbaummontage ist Handarbeit auf dem Formbrett. Ein XR-System braucht den Leitungssatz als 1:1-Brettlayout, das die KBL-Datei nicht enthält.
  • Ziel: ein datengetriebener Trainer, der ohne Installation auf der Meta Quest 3 läuft.

Wie?

  • Python-Pipeline: die KBL des öffentlichen VW-Beispiels „Old Beetle“ wird auf ein Formbrett in wahren Segmentlängen abgewickelt; Pins folgen aus der Topologie.
  • WebXR-App mit Handtracking: Leitung für Leitung verlegen, jeder Pin wird geprüft; geführter und Testmodus; Zeit, Fehler und Hinweise werden protokolliert.

Ergebnisse

  • 18 Leitungen, 20 Stecker; die KBL-Leitungslängen stimmen auf den Millimeter mit den Brettpfaden überein.
  • Live-Demo: suavi-yildirim.github.io/formboard-xr
