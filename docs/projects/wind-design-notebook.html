Wind Design Notebook

Personal project | 11/2026 | Concept, calculation, implementation

Tower calculator with formula, assumptions and source

DesignAI / SimulationStructural dynamicsFEPythonJavaScript
Open the live demo ↗Code on GitHub ↗

What?

  • A personal learning project on wind turbine design, following one turbine through rotor, tower and road. Public sources only, with no link to any manufacturer.

How?

  • Tower module for tubular steel and hybrid towers: natural frequency in the 1P/3P window, stress as a load indicator, transport, concrete parts and crane, each as a utilisation.
  • Every result shows its formula, assumptions and source; the model's limits, such as fatigue and buckling, are stated on the page.

Results

  • The natural frequency (Rayleigh) agrees with an independent FE model in Python to under 0.2%.
  • A design-space map of 1,600 variants shows which check governs where. A learning notebook, not a design tool.
